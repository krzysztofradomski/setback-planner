# Workspace UI review and correction

The previous release exposed most features in one scrolling rail, interleaved object properties with terrain and administrative tools, mixed languages, used no manufacturer imagery, and was reviewed with too few real user journeys. The correction retains the working geometry/editor and reorganizes the workspace instead of replacing it.

## Layout and interaction

A persistent header contains sharing, report export and language selection. A narrow navigation rail separates Houses, Parcel, Garden, Project and Presentation. The library is distinct from the central canvas and the selected-object inspector. On phones the library becomes a horizontally browsable house sheet; the inspector has a bounded height and an explicit Back to plan action. Tablet panel dismissal returns its space to the canvas.

The Udana Budowa catalog uses public manufacturer photos and dimensioned plans. DE75, DE105, DE135 and DE165 can be placed using verified exterior envelopes. Plans have named dialogs, zoom/pan, full-size access and localized labels. Catalog source assets and measurement provenance are recorded in `static/assets/udana-budowa/README.md`. Numeric heights/pitch and detailed openings remain illustrative; the product distinguishes user-changed dimensions.

Windows and doors have ordinary form controls; raw JSON geometry remains an advanced option. Map layer selection lives with the parcel workflow instead of crowding the map canvas. Source descriptions and coverage caveats are localized. Optional layers use the same official providers observed in Gruntometr's public report; the app never calls Gruntometr's report APIs.

## Independent review findings addressed

- Tablet dismissal left a reserved blank grid column: collapsed layout now reclaims it.
- Mobile inspector covered placement feedback: bounded bottom sheet plus explicit Back to plan.
- Inspector navigation state disagreed with the displayed panel: centralized pressed state and focus target.
- Phone floor-plan dimensions were unreadable: zoom/pan and full-size access; zoom centers on the drawing rather than blank margins.
- Floor-plan dialog lacked an accessible name and localized labels: heading association, close label and image description added.
- Moving toolbars broke mobile plan fitting: bounds now reserve the correct top/bottom space.
- Static catalog files were not included by the old Vite setup: dedicated `static` public directory, build verification and production catalog journey added.

## Verification approach

Inspect actual browser screenshots and flows at 320, 390, 768, 1024 and 1440 pixels, in English and Polish. Cover catalog image loading, plan dialog, placement and sharing, layers, mobile dismissal/inspector, tablet resizing and 3D. Keep the existing editing/import/privacy/showroom regressions. Production smoke tests now include the new workspace and asset journeys as well as map, 3D and reports.
